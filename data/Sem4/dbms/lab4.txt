What is MongoDB?
      MongoDB is a NoSQL database that stores data in the form of JSON-like documents instead of tables and rows.


What is mongosh?
    mongosh is the MongoDB shell used to interact with the MongoDB server and execute commands.

What is a Collection?
    A collection is a group of documents in MongoDB. It is similar to a table in relational databases.

What is a Document?
   A document is a record in MongoDB stored as key-value pairs.
Example
{ id:1, name:"Taste of Italy", cuisine:"Italian" }

What is _id in MongoDB?
   _id is a unique identifier automatically created by MongoDB for each document.


What is insertMany()?
   insertMany() is used to insert multiple documents into a collection at the same time.
Example
db.restaurants.insertMany([...])


What is find()?
   find() is used to retrieve documents from a collection.
Example
db.restaurants.find()

What is Projection in MongoDB?
   Projection is used to display only selected fields in the output.
Example
{ name:1, address:1, _id:0 }


What does “use restaurantDB” do?
   It creates or switches to the database named restaurantDB.

What is an Embedded Document?
   An embedded document is a document inside another document.
Example
address:{ building:"12A", street:"MG Road" }

Why is MongoDB called NoSQL?
    MongoDB is called NoSQL because it does not use traditional SQL tables and rows. It stores data in document format.


Difference between SQL and MongoDB
   SQL → Table, Row, Column
   MongoDB → Collection, Document, Field
